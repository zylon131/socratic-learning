# 问学 · 家庭学习服务

直接面向家长和孩子的 C 端学习应用。一个家长账号管理多个孩子档案，作业批改、自主学习、错题巩固、复习记录和学科学习档案连在一起。各孩子、各学科分别保存阶段、目标、会话与学习证据。

## 当前范围（2026-11-19）

按用户最新决定，已移除全部积分功能：没有钱包入口、注册赠送、余额门槛、自动续充、扣费或退款流程。学习与作业处理不再依赖钱包记录。历史积分表与历史费用值仅作兼容保留，不删除已有数据；新会话和作业不写费用。

教学采用 Chat Completions 流式接口，由本地教学编排层协调上下文、任务、互动组件、学习证据和状态。现有 AGENT_MODE=harness 是兼容配置名称，当前教学调用不经过 DSH SDK。

## 本地运行

在项目目录执行：

```powershell
npm.cmd install
npm.cmd run build
npm.cmd start
```

开发模式使用 `npm.cmd run dev`。打开 http://127.0.0.1:4175，注册或登录家长账号。项目脚本使用本地安装的 Node 24。

复制 `.env.example` 为 `.env`，设置项目自己的模型凭据：

- 教学：`TEACHER_API_KEY`、`TEACHER_BASE_URL`、`TEACHER_MODEL`；未配置时回退对应 `HOMEWORK_*`。
- 图片批改：`HOMEWORK_API_KEY`、`HOMEWORK_BASE_URL`、`HOMEWORK_MODEL`。
- 数据库：设置 `DATABASE_URL` 使用 PostgreSQL，否则使用 `.local/db` 中的 PGlite。
- 正常运行默认使用真实模型；演示模式仅允许 `NODE_ENV=test` 且配置隔离数据目录的测试环境。不会因为缺少凭据而自动切成演示回复。

## 已实现

- 注册、登录、孩子档案，以及按孩子和学科隔离的学习记录。
- 教师文本流式输出、文本内图示和互动探索、输入排队、历史恢复。
- 作答后的教师接续、主任务暂停、前置知识补习及返回原任务。
- 学习证据、技能状态、课程目录、学习建议和评测记录。
- 作业逐页上传、图片鉴权、持久批改任务、重试、防重复提交、原题进入带学及复习自述。
- 技术失败保留可恢复的学习记录并显示错误；每个账号最多同时处理 12 页作业。

## 验证与边界

本机知识图谱预览使用 `.local/curriculum/cn-math-taxonomy/curriculum.json`。设置 `CURRICULUM_TAXONOMY_FILE` 并指定独立 `LOCAL_DATA_DIR`，保持回环监听，即可在课程目录中搜索上游知识点，按稳定 ID 开始学习。该文件覆盖 10 科、3,557 个知识点和 5,132 条先修关系，随本地预览保存作者与许可说明。预览用途和部署核查见 [学习交互与部署核查](./docs/学习交互与部署核查-2026-11-19.md)。

`npm test` 使用独立 PGlite 和模拟模型，覆盖迁移、账号与孩子隔离、图片权限、幂等、失败重试、服务重启、教学任务与互动组件，以及没有钱包记录时的完整学习/作业流程。构建使用 `npm run build`。

当前专用确定性学科校验器覆盖数学和化学的部分内容，其余学科使用通用适配器；课程目录是初始内容，不代表完整中小学知识体系。原图存储为数据库 bytea，作业 worker 为单进程实现。完整知识体系、真实多学科教学质量评测、生产 PostgreSQL 联调及部署仍需后续完成。

历史设计文档中的积分、收费与退款章节均不再适用，当前实施状态以本文件和 `docs/实施进度.md` 为准。
