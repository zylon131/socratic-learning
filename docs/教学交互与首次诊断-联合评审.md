# 教学交互与首次诊断联合评审

2026-11-19。依据龙哥提供的两份方案、问学当前代码、4194 的高一数学原会话和本次内存解析复现。结论是先把学段开场、点选续讲和普通计算题的接续做顺，再修图解的实时渲染，随后按明确的学习目标做可跳过的快速摸底。现有学习会话、任务、证据和内容块可以复用。

## 首次诊断 PRD 的三处修订

1. **首次学习与主动摸底要有不同入口。** 第 2 节允许明确目标直接教学，第 5 节又规定无证据先出题，第 9 节把首屏简化为问学生学什么。统一成三条路径。明确专题直接开讲；只明确学段时给少量章节和推荐入口；主动要求摸底时才安排连续探测。正常带学可以在讲解和练习中自然观察，出现影响当前主题的具体缺口再提出局部补学。
2. **预算限制的是额外打断。** “约 2–4 次”只作为显式摸底的软预算。已有证据足够、找到可教学起点或学生想直接学时提前结束。确认的是本次目标的起点，例如“可以从区间内的函数变化开始”，其余能力仍可待观察。答对普通计算题后可以直接推进；如果推理过程本身是目标，题面从开始就让学生写关键步骤。
3. **选题要有证据和可用的题。** 现有知识点与先修关系可帮助收窄范围，实际出题仍需可核对的题面、答案依据和版本。按本次目标及相关先修取同科历史证据。证据不足或冲突时保留未知，并允许学生选择先学。先复用会话、任务、作答事件、证据及能力状态。显式诊断需要恢复时，优先在会话状态追加小块诊断上下文，保存当前目标、剩余预算、原题和停止原因。出现必须独立查询多次诊断的需求时再评估单独的数据表。

## 合并实施与验收

1. **先走学生这条主线。** 从空档案输入“帮我学习高一数学”，显示对应阶段的几个章节。点章节直接开讲，做一题正常推进。再用初中英语复测。检查点 B 在两道不同题里会带出各自的选项，允许文字补充理由，刷新能继续点评。化学用作原有学科回归。
2. **再测一条真正需要富内容的带学路径。** 用数学函数或分数验证讲解、图解、题卡同消息混排，遇到表达困难能换图。比较表能讲清楚时可用表，明确要求探索时再显示可操作图。关掉某一组件支持，确认界面解释降级，日志可定位，回退不能算图解验收通过。主动要求完整示范时直接讲完。
3. **最后加入可选摸底。** 从“看看我在这个专题从哪开始”进入。覆盖已有证据、理由可靠、猜对、不知道、跳过、历史冲突和恢复。检查答题预算、停止原因，以及继续学习后能回到原目标。每条关键用例保留真实浏览器表现、结构化事件和数据库终态。

实施复用当前响应帧、SSE 组件事件和数据库对象。新增会话字段为可选字段，既有题号和历史只读行为继续可用，旧会话可继续教学。

- 桌面用真实模型验证高一数学从空档案进入、点选“函数入门与单调性”、正文与关系图及题卡混排。两道不同题分别点 B，回显各自选项且老师自动续讲。
